快捷键与隐私

在 YouTube 播放页生效（未与 YouTube 自带快捷键冲突）

  • Alt + Z循环切换中文字幕：隐藏 → 悬停显示 → 常显
  • Alt + [减小中文字幕字号
  • Alt + ]增大中文字幕字号
  • Alt + E启用 / 关闭双语字幕

隐私说明

  • DeepSeek API Key 仅保存在本机 chrome.storage.local，不会同步、不会上传到除 DeepSeek API 之外的任何服务器。
  • 只有需要翻译的字幕文本与点击查询的单词会发送给你配置的 DeepSeek API（默认 https://api.deepseek.com）。
  • 翻译与查词结果缓存在本机，词库也只保存在本机；卸载扩展即全部清除。
  • 扩展不收集浏览记录，不注入广告，不请求第三方统计脚本。
